### Featured Work

#### OT-Based SOC Incident Response Platform
Developed inside the CENTER SAU Water Management Testbed.

- Correlates OPC UA simulator tag changes from KEPServerEX and UaExpert with Suricata network-flow evidence.
- Uses a Python OPC UA subscription monitor, Wazuh rules, Django REST Framework, PostgreSQL, and a Next.js dashboard.
- Supports live Wazuh Indexer polling, backend case creation, Swagger/OpenAPI documentation, Docker Compose deployment, and Windows/Ubuntu lab automation scripts.
- Includes DevSecOps validation through automated tests, Docker validation, Wazuh rule checks, secret scanning, static analysis, and dependency audits.

#### AI-SOC
AI-assisted multi-agent security incident investigation platform.

- Normalizes Wazuh alerts and converts high-priority detections into structured incident case files.
- Implements triage, evidence collection, reconnaissance validation, MITRE ATT&CK mapping, and analyst-ready reporting.
- Built with FastAPI, LangGraph, PostgreSQL, Wazuh, Next.js, Docker, and MITRE ATT&CK.

#### Real-Time SDN Intrusion Detection System
Streaming IDS pipeline for live network traffic.

- Built with Apache Spark, Mininet, Floodlight, CICFlowMeter, Docker, and Random Forest.
- Processed live HTTP, TCP, and MQTT traffic from ESP32-based IoT devices.
- Trained on CSE-CIC-IDS2018 and visualized attack results in Apache Superset.

#### Privacy-Preserving Threat Analytics
Secure analytics pipeline for IDS datasets.

- Built a three-party additive secret-sharing system for privacy-preserving threat analytics.
- Aggregated 7.26 million IDS records while matching centralized baseline results.
- Used Python, Docker, PostgreSQL, and Apache Superset.
